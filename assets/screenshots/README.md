# Capturas e demonstração

Depois de configurar seus sons e dispositivos, coloque aqui:

- `biblioteca.png`: janela principal no tema escuro.
- `biblioteca-clara.png`: janela principal no tema claro.

Use apenas áudio e nomes que possa publicar. Os testes geram capturas em
`qa-artifacts/`, que ficam fora do Git e mostram uma biblioteca fictícia.
