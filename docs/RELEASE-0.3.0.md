# CrashSounds 0.3.0 — novo nome

O soundboard agora se chama **CrashSounds**.

Nome novo no app, bandeja, instalador, atalhos, ícone e documentação.
Instalador por usuário sem administrador e ZIP com criar-atalho.bat.

Baixe **CrashSounds-0.3.0-setup.exe**, feche o app antigo pela bandeja e instale.
Mantenha “Criar atalho na área de trabalho” marcado para abrir com um clique.
Prefere portátil? Extraia todo o ZIP e execute criar-atalho.bat.

A pasta de dados permanece %LOCALAPPDATA%\EcoDeck para compatibilidade.
Backups antigos continuam aceitos. Não há exclusão dos sons pessoais.

Executável sem assinatura digital: consulte o guia SmartScreen no README.
Pré-release: validação auditiva em headset, cabo virtual, Discord e jogos pendente.
