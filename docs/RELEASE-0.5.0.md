# CrashSounds 0.5.0

O botão **Baixar por link** agora aparece também no topo da biblioteca.

O aviso de **Parar sons** desaparece após 2,5 segundos. O X encerra o app;
abrir pelo atalho traz a janela existente para a frente.

## Atualizar

Se estiver na versão 0.3.0 ou 0.4.x, clique com o botão direito no ícone do
CrashSounds perto do relógio e escolha **Sair** antes de executar o instalador.
Isso evita o erro de arquivo aberto para gravação. A biblioteca é preservada.

Baixe **CrashSounds-0.5.0-setup.exe** para instalar ou o ZIP para usar portátil.
O executável não possui assinatura digital; confira a procedência e os checksums.

Validação: testes isolados de interface, IPC entre processos, biblioteca, áudio
com dispositivos falsos e downloads sintéticos. Dispositivos físicos e links
dos sites utilizados continuam dependendo de teste manual.
